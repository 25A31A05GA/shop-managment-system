# Case studies

Seven worked cases. Each one is a **synthetic walk-through** built from numbers the engine really produces for the sample supermarket on 8 November 2026 (Diwali day). None is about a real person or shop.

| # | Case | Module | Lesson |
|---|---|---|---|
| [1](01-diwali-stock-out.md) | Diwali morning: 154 products to order | `stock` | Festival demand is not a normal day |
| [2](02-the-offer-that-lost-money.md) | The 1+1 offer that sold out and lost money | `insights` | Fast selling is not profit |
| [3](03-which-rice-is-better.md) | Which rice do customers really prefer? | `insights` | Separate preference from price and shelf |
| [4](04-short-drawer.md) | The counter that is short by ₹330 | `cash` | A lead, not an accusation |
| [5](05-late-credit.md) | ₹1.52 lakh of late credit | `ledger` | Remind the oldest first |
| [6](06-small-shop-forecast.md) | The kirana forecast that says "rough guide" | `forecast` | Honest uncertainty |
| [7](07-room-to-raise-price.md) | Sona Masoori: room to raise ₹3 | `pricewatch` | Small, safe price moves |
