# Recruiter kit

**One line:** A zero-dependency Python engine and live dashboard that gives Indian shop owners plain-language, back-tested answers about sales, stock, offers, credit and cash.

## Try it in 60 seconds
1. Open the [live dashboard](https://25a31a05ga.github.io/shop-managment-system/dashboard.html) and pick "Chairman / Owner".
2. Click **Forecast** and read the "How sure is this?" card.
3. Run `python -m dukan_drishti brief` in the repo.
